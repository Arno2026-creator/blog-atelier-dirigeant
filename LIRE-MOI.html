🚀 Mettre votre blog en ligne

Guide complet — hébergement gratuit sur Netlify · Ajouter des articles · Gérer les ressources

Partie 1 — Mettre le blog en ligne gratuitement 100 % gratuit

1

Créer un compte Netlify

  1. Ouvrez votre navigateur et rendez-vous sur www.netlify.com
  2. Cliquez sur Sign up (inscription gratuite)
  3. Choisissez Sign up with email
  4. Saisissez votre adresse email et choisissez un mot de passe
  5. Validez votre email (vérifiez votre boîte mail)
  6. Vous arrivez sur votre tableau de bord Netlify
2

Mettre le blog en ligne (glisser-déposer)

  1. Dans votre tableau de bord Netlify, faites défiler jusqu'à la section "Want to deploy a new site without connecting to Git?"
  2. Vous voyez une zone avec le texte "Drag and drop your site output folder here"
  3. Ouvrez l'explorateur de fichiers de votre ordinateur
  4. Localisez le dossier blog-atelier-dirigeant (le dossier que vous avez téléchargé)
  5. Faites glisser ce dossier entier dans la zone de dépôt Netlify
  6. Netlify déploie automatiquement votre blog — attendez 30 secondes
  7. Netlify vous donne une URL temporaire du type : random-name-123.netlify.app
  8. Cliquez sur cette URL pour vérifier que votre blog s'affiche correctement
✅ Votre blog est en ligne ! Il est accessible depuis n'importe quel appareil dans le monde entier.
3

Connecter votre nom de domaine latelierdudirigeant.fr

Pour que votre blog soit accessible à latelierdudirigeant.fr/blog, vous avez deux options :

Option A — Sous-domaine blog.latelierdudirigeant.fr (plus simple)

  1. Dans Netlify, cliquez sur Domain settings
  2. Cliquez sur Add custom domain
  3. Saisissez : blog.latelierdudirigeant.fr
  4. Connectez-vous à votre espace client IONOS
  5. Allez dans Domaines > DNS > Gérer les zones DNS
  6. Ajoutez un enregistrement CNAME : blog → votre-site.netlify.app
  7. Attendez 15 à 30 minutes — votre blog est accessible à blog.latelierdudirigeant.fr

Option B — Contacter le support IONOS

Appelez le support IONOS et demandez-leur d'ajouter un enregistrement CNAME pour le sous-domaine "blog" pointant vers votre URL Netlify. Ils le feront en 5 minutes.

Partie 2 — Publier un nouvel article

1

Dupliquer un article existant

  1. Ouvrez le dossier blog-atelier-dirigeant/articles/ sur votre ordinateur
  2. Copiez le fichier reprendre-commerce-erreurs.html
  3. Collez-le dans le même dossier
  4. Renommez-le avec le sujet de votre article, en minuscules et sans espaces
    Exemple : gestion-stock-commerce.html
2

Modifier le contenu de l'article

Ouvrez le fichier HTML avec un éditeur de texte. Sur Windows : clic droit → "Ouvrir avec" → Bloc-notes. Sur Mac : clic droit → "Ouvrir avec" → TextEdit.

Éléments à modifier :

  • <title> — Le titre de l'onglet navigateur (pour le SEO)
  • <meta name="description"> — La description Google (155 caractères max)
  • <h1> — Le titre principal de l'article
  • La date, la catégorie, le temps de lecture
  • Le contenu entre les balises <article class="article-content"> et </article>
💡 Astuce : Utilisez Ctrl+H (Windows) ou Cmd+H (Mac) pour remplacer rapidement le texte existant par votre nouveau contenu.
3

Ajouter l'article à la page d'accueil

  1. Ouvrez le fichier index.html avec votre éditeur de texte
  2. Trouvez la section <div class="articles-grid">
  3. Copiez un bloc <article class="article-card">...</article> existant
  4. Collez-le en premier dans la grille (pour qu'il apparaisse en tête)
  5. Modifiez le titre, l'extrait, la catégorie et le lien vers votre nouveau fichier
4

Remettre en ligne sur Netlify

  1. Connectez-vous à votre compte Netlify
  2. Cliquez sur votre site
  3. Cliquez sur Deploys
  4. Faites glisser à nouveau le dossier blog-atelier-dirigeant entier dans la zone de dépôt
  5. Netlify met à jour votre blog en 30 secondes
  6. Votre nouvel article est en ligne ✅

Partie 3 — Ajouter une ressource téléchargeable

1

Déposer votre fichier PDF ou Excel

  1. Copiez votre fichier PDF ou Excel dans le dossier blog-atelier-dirigeant/ressources/
  2. Nommez-le clairement, sans espaces ni accents
    Exemple : checklist-reprise-commerce.pdf
2

Créer le lien de téléchargement

  1. Ouvrez le fichier ressources.html
  2. Trouvez la carte de ressource correspondante
  3. Remplacez href="#" par href="ressources/checklist-reprise-commerce.pdf"
  4. Supprimez l'attribut onclick="alert(...)"
  5. Ajoutez download pour forcer le téléchargement
  6. Résultat : <a href="ressources/checklist-reprise-commerce.pdf" download class="resource-download">
3

Remettre en ligne

Faites glisser à nouveau le dossier complet sur Netlify. Votre ressource est téléchargeable en ligne.

Partie 4 — Activer la newsletter Brevo

1

Connecter Brevo au formulaire d'inscription

  1. Créez votre compte gratuit sur www.brevo.com
  2. Créez une liste "La Minute du Dirigeant"
  3. Créez un formulaire d'inscription dans Brevo
  4. Copiez l'URL d'action du formulaire Brevo (disponible dans les paramètres du formulaire)
  5. Dans chaque fichier HTML, trouvez les balises <form class="newsletter-form" onsubmit="return false;">
  6. Remplacez onsubmit="return false;" par action="VOTRE_URL_BREVO" method="POST"
  7. Remettre en ligne sur Netlify
